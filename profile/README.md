## 关于协会

燕山大学学生网络信息协会 (YUNA) 是一个致力于在燕山大学推广计算机科学和技术的学生组织。协会为成员提供广泛的学习与实践平台，涵盖了从 Web 开发、网络安全、服务器运维到高性能计算等多个领域。我们的目标是培养技术人才，促进学生的技术能力提升与职业发展。

## 主要部门

- **开发部（YUNA devBranch）**：开发部专注于 Web 应用与软件系统开发，同时承担协会内部网络基础设施建设以及前沿技术探索任务。我们坚持“项目驱动”与“技术共享”的理念，为成员提供从基础入门到工程实践的完整成长路径。无论是刚接触编程的新手，还是希望深入探索底层技术的开发者，都能在这里找到适合自己的方向。

  - **Web 前端开发**：从网页基础到现代化应用构建，学习 HTML、CSS、JavaScript 等核心技术，掌握响应式布局与交互设计。进一步接触 Vue.js、React 等主流前端框架，理解组件化开发思想，能够独立构建复杂 Web 应用。

  - **Web 后端与全栈开发**：学习 Node.js、Python、Java 等后端开发技术，掌握服务器端程序设计、数据库管理以及接口开发。通过 MySQL、Redis、MongoDB 等技术实践，理解数据存储、业务逻辑与前后端协作，逐步成长为具备完整项目开发能力的全栈开发者。

  - **工程化与软件协作**：开发部注重真实软件工程流程训练，成员将学习 Git 版本控制、GitHub/GitLab 协作开发、代码审查（Code Review）、接口规范设计以及基础 CI/CD 流程，让代码不仅“能运行”，更具备可维护、可协作、可持续迭代的工程质量。

  - **项目实践与技术探索**：开发部坚持以实际项目推动技术成长，成员可参与协会内部系统建设、校园应用开发以及计算机相关竞赛项目，包括计算机设计大赛、“互联网+”、挑战杯等赛事作品。同时，我们鼓励探索移动端开发、自动化脚本、开源项目协作、算法与系统方向研究，让每一个想法都有机会从概念变成真正可用的产品。

- **网络安全部**：网络安全部是协会最早成立的部门之一，前身为 CTF 部，主要负责网络安全知识学习、CTF 竞赛训练以及安全技术研究。我们围绕“安全基础”与“攻防实践”展开培养，通过理论学习、工具使用和实战挑战，帮助成员逐步建立网络安全知识体系，探索网络世界背后的安全机制。

  - **网络安全基础**：从计算机基础知识出发，学习 Linux 系统、安全工具、网络协议以及 Python 脚本编写等内容。通过掌握 Kali Linux 等安全环境和常用工具，为后续漏洞分析与安全研究打下基础。

  - **CTF 竞赛与攻防实践**：部门长期参与各类网络安全攻防与 CTF 比赛，涵盖 Web 安全、密码学、逆向分析、二进制漏洞利用、信息搜集等方向。成员将在真实比赛环境中解决安全挑战，提升漏洞发现、分析和实践能力。

  - **漏洞挖掘与安全研究**：围绕 Web 漏洞、软件安全、移动端安全等方向开展技术探索，学习漏洞原理、攻击方式以及安全防护方法。通过实验环境和项目实践，加深对互联网安全问题的理解。

  - **竞赛培养与技术交流**：协会拥有丰富的网络安全竞赛经验，曾有成员在相关比赛中取得成绩。部门会提供学习资料、训练指导和技术交流平台，帮助不同基础的成员逐步成长。

  - **安全技术探索**：除了竞赛训练外，网络安全部也鼓励成员探索网络爬虫、安全工具开发、安全知识分享等方向，让成员不仅能够发现问题，也能够理解并构建更加安全的网络环境。
  
- **运维部（YUNA Ops）**：运维部负责协会各类技术服务的稳定运行与长期维护，是连接开发成果与实际应用场景的重要保障。部门专注于服务器管理、网络环境建设、自动化运维以及技术平台维护，让每一个项目不仅能够被开发出来，更能够稳定、持续地服务用户。

  - **Linux 服务与系统运维**：学习 Linux 系统管理、服务器部署、权限管理、日志分析、故障排查等基础运维技能。成员将参与协会网站、应用平台以及内部服务的部署与维护，理解一个线上系统从运行到保障的完整流程。

  - **自动化运维与工程实践**：探索现代 DevOps 工作方式，学习 Docker、CI/CD、Shell、Python 自动化脚本等技术，提高服务部署和管理效率。通过自动化工具减少重复工作，让运维流程更加高效、可靠。

  - **网络与基础设施建设**：参与域名、服务器、网络服务以及各类技术环境的建设与管理，为协会项目提供稳定的运行基础。同时协助其他部门完成项目部署、环境配置和上线支持，保障技术成果顺利落地。

  - **平台维护与技术保障**：负责协会现有技术服务和校园平台的日常运行，包括版本更新、性能优化、安全维护以及异常处理。成员将在真实服务场景中积累经验，提升解决实际问题的能力。

  - **云计算与技术探索**：运维部不仅关注已有系统维护，也鼓励成员探索云计算、容器化、网络技术、DevOps 工程等方向。从服务器上的一条命令，到用户访问服务时的一次响应，运维部致力于让技术真正稳定运行，让创造持续产生价值。

- **组宣部**：组宣部融合原组宣部与秘书处的核心职能，是连接协会内部成员与外部受众的重要桥梁。部门主要负责协会形象建设、文化运营、活动组织以及日常事务管理，通过内容传播与组织协调，推动协会品牌建设和团队凝聚力提升。

  - **宣传运营与品牌建设**：负责协会官方平台的运营与内容策划，包括活动宣传、视觉设计、信息发布以及对外沟通等工作。成员将参与协会形象塑造，学习如何通过内容创作提升组织影响力。

  - **活动策划与组织管理**：参与协会活动的规划、执行与总结，学习活动流程设计、策划方案撰写以及资源协调等能力。通过实际活动运营，提升组织能力和项目管理经验。

  - **内部文化建设**：负责协会内部氛围营造与成员关系维护，推动部门交流、团队建设以及组织文化发展。成员将在协作过程中增强沟通能力，提升团队协作水平。

  - **综合能力培养**：加入组宣部不仅能够学习 Adobe 系列设计工具、文案策划等实用技能，也能在实际工作中锻炼沟通表达、协调管理和问题解决能力，为未来学习、工作和团队合作积累经验。

  - **组织连接与发展支持**：作为协会的重要协调部门，组宣部负责连接不同部门成员与外部合作资源，为协会各项活动和技术项目提供宣传、组织与支持，让优秀成果能够被更多人了解和参与。
